# 智能增量扫描开发路线

## 目标
实现智能增量扫描功能，只重新扫描变化的目录，提升扫描效率。

## 核心思路
1. 在缓存中记录每个目录的修改时间
2. 加载缓存时，检查目录是否变化
3. 只重新扫描变化的目录
4. 合并新旧数据，保持树结构完整

## 风险与挑战

### 技术风险
1. **数据一致性**：合并数据时可能出现不一致
2. **性能问题**：大量变化时可能比全量扫描还慢
3. **边界情况**：移动、重命名等复杂场景

### 解决方案
1. 严格的数据验证和测试
2. 设置阈值，变化超过30%时自动切换全量扫描
3. 充分的测试覆盖
