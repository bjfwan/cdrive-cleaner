## 关键指标说明

### 1. 快速扫描计算大小
- 通过累加所有扫描到的文件大小得出
- 包括根目录直接文件和所有子目录文件

### 2. 深度扫描遍历统计
- 在遍历文件树时实时累加的统计数据
- 每遇到一个文件就累加其大小

### 3. 深度扫描目录树累加
- 先统计每个目录的直接文件
- 然后从最深层开始向上累加子目录大小
- 这是最终返回给前端的数据

### 4. 磁盘真实使用大小
- 通过 Windows API `GetDiskFreeSpaceExW` 获取
- 表示磁盘实际已使用的空间
- 是验证扫描准确性的基准

## 数据准确性判断标准

### ✓ 数据准确性良好
- 计算大小与磁盘真实大小差异 ≤ 5%
- 深度扫描的遍历统计与目录树累加一致

### ⚠️ 警告：可能存在问题
- 计算大小与磁盘真实大小差异 > 5%
- 深度扫描的遍历统计与目录树累加不一致

## 常见差异原因

1. **系统文件和隐藏文件**
   - 某些系统文件可能无法访问
   - 隐藏文件可能被跳过

2. **符号链接**
   - 设置了 `follow_links(false)`，不跟随符号链接
   - 符号链接本身的大小很小

3. **文件系统元数据**
   - 磁盘使用包括文件系统元数据
   - 扫描只统计文件内容大小

4. **权限问题**
   - 某些文件或目录可能无权访问
   - 会在 `无法访问` 计数中体现

5. **缓存问题**
   - 快速扫描使用缓存可能导致数据过时
   - 缓存命中时会显示 `[缓存命中]` 日志

## 调试建议

1. **检查无法访问的文件数**
   - 如果数量很大，可能影响准确性

2. **对比快速扫描和深度扫描**
   - 两者结果应该接近
   - 差异较大说明缓存或计数逻辑有问题

3. **查看缓存命中日志**
   - 确认缓存是否正确工作
   - 必要时清除缓存重新扫描

4. **检查内部一致性**
   - 深度扫描的两个统计值应该一致
   - 不一致说明累加逻辑有问题
