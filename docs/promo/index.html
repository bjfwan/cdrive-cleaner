Core Features

从扫描到迁移，一站式解决

不只是告诉你空间去哪了，还帮你安全地搬走它

极速磁盘扫描

管理员模式走 NTFS MFT + USN Journal，几十万文件秒级完成。普通权限自动回退原生枚举，功能不打折。第二次扫描走增量，只重扫变更子树。

多维空间分析

Treemap 面积图一眼看胖子，List 列表按大小/名称/时间排序，Large Files 跨目录挑大文件，Smart Groups 自动分组标记可清理/可迁移/系统关键。

目录安全迁移

copy → verify → backup → create-link → cleanup 五步事务。原位置留 Junction/Symlink，应用零感知继续运行。CopyFile2 大文件 unbuffered IO + Rayon 并行复制。

四级安全检测

迁移前自动跑安全分析：路径白名单 → 应用类型识别 → reparse 深度 → 进程占用 → 注册表关键键。系统关键目录硬拒绝，绝不踩坑。

游戏库一键迁移

自动识别 Steam / Epic / Game Pass 已安装游戏，免去手工找路径。Junction 链接让启动器无缝运行，专属迁移记录追踪每一款游戏。

历史回滚 & 趋势

每次迁移完整记录到 SQLite (WAL)，一键回滚到原状。Space Trend 90 天空间走势图，持续监控磁盘健康。重复文件检测 (xxhash) 批量清理。

Tech Stack

现代技术栈驱动

原生性能 + 现代前端 + 类型安全，每个技术选型都有理由

Rust

后端核心语言，零成本抽象 + 内存安全。MFT 解析、文件操作、并发复制全部 Rust 实现，无 GC 暂停。

Tauri 2

桌面应用框架，Rust 后端 + WebView 前端。安装包仅 5MB，内存占用远低于 Electron，原生系统集成。

Vue 3

前端 UI 框架，Composition API + 响应式系统。Treemap、列表、趋势图等复杂交互组件均基于 Vue 3 构建。

TypeScript

前端类型安全，严格模式编译。Tauri IPC 通信层全量类型定义，前后端接口零歧义。

SQLite + WAL

本地数据库，WAL 模式支持并发读写。迁移记录、扫描缓存、空间趋势数据全部持久化存储。

NTFS MFT/USN

Windows NTFS 原生 API，MFT 全量解析 + USN Journal 增量追踪。磁盘扫描性能的核心加速引擎。

ECharts

数据可视化引擎，Treemap 矩形树图、折线趋势图、饼图占比分析。Canvas 渲染，大数据量下依然流畅。

Element Plus

Vue 3 UI 组件库，提供表格、对话框、进度条等基础组件。暗色主题深度定制，与整体设计语言统一。

Rayon + Tokio

Rayon 数据并行（文件复制、校验）+ Tokio 异步运行时（IPC 通信、后台任务）。CPU 密集和 IO 密集各得其所。
