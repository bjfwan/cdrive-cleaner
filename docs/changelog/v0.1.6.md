## CSD v0.1.6

本次版本聚焦清理、搬运和诊断链路的稳定性：清理过程有实时进度和失败明细，已知文件夹重定向更可控，历史记录和诊断包也更适合排查问题。

### 新增功能

- 垃圾清理增加实时进度事件，界面会显示当前路径、已完成项目、清理体积和失败数量。
- 清理完成后保留失败项目摘要，最多展示前 5 条失败路径和错误原因，便于继续处理被占用或权限不足的文件。
- 已知文件夹重定向增加推荐目标路径，选择磁盘根目录时自动落到 Documents / Downloads 等对应子目录。
- 文件夹重定向增加进度反馈，并将成功移动文件的记录写入历史，支持在历史页识别和回滚重定向记录。
- 设置页新增诊断包导出，包含最近日志和环境信息，导出后自动在资源管理器中定位。

### 修复

- 修复带进度回调的删除任务在遇到锁定文件时可能卡住的问题。
- 垃圾扫描结果按路径去重，避免同一文件被多条规则重复计入或重复选择。
- 空间分解不再把 Program Files、Program Files (x86)、ProgramData、Users 这类集合根目录标记为可整体搬迁，并补充对应解释。
- 历史弹窗高度和内部滚动结构调整，避免记录列表在弹窗内溢出或无法滚动。
- 购物车删除增加实时百分比反馈，删除大目录时不会长时间停留在静态状态。

### 工程化

- 日志同时写入本地 rolling log 文件，并保留控制台输出，诊断导出可直接收集最近日志。
- 新增删除进度防挂、已知文件夹推荐路径、Program Files 根目录解释等回归测试。
