## CSD v0.1.7

本次版本聚焦空间统计可信度、缓存稳定性和弹窗交互体验：系统保留/NTFS 元数据差额不再被误称为“漏算”，扫描缓存更能抵抗结构变更，默认存储、迁移、历史回滚和清理界面也更清晰稳定。

### 新增功能

- 空间统计新增“系统保留/卷元数据”指标，用于展示卷级已用空间与普通文件扫描体积之间的差额。
- 空间分解新增“系统保留/卷元数据”非可操作分类，覆盖 NTFS 元数据、MFT/USN、卷影副本、还原点和簇分配差额等不属于普通目录树的空间。
- 默认存储迁移结果在弹窗行内展示成功体积或失败原因，不再只依赖 Toast 提示。
- 垃圾清理和列表视图补充更细的选择、反馈和结果展示，清理失败场景更容易定位。

### 修复

- 将原“漏算量”统一改为“系统保留/卷元数据”，避免用户误以为扫描失败或漏扫。
- 修复扫描缓存因 bincode 结构变更反复判 corrupt 的问题；新缓存保留 JSON 兜底，并在 bincode 失败时自动回退 JSON。
- 升级扫描缓存 schema，旧快照会自动重建，避免复用缺少系统保留差额字段的缓存。
- 增量扫描完成后重新计算系统保留/卷元数据差额，避免沿用过期值。
- 修复迁移完成页闪一下就关闭的问题，迁移成功后保留完成反馈，用户点击“完成”后再关闭。
- 迁移中禁止点击背景或关闭按钮打断操作，减少误关闭造成的状态混乱。
- 默认存储弹窗改为稳定滚动条，并提升弹窗层级，避免被其他面板遮挡。
- 历史记录的回滚按钮移动到记录头部，确认弹窗层级提升，操作入口更明显。
- 修复设置页“关于”区域乱码文案。

### 工程化

- `ScanResult` 增加 `system_reserved_bytes` 字段，并在 Native、MFT+USN、增量扫描和索引快照中保持一致。
- 缓存读取增加 bincode -> JSON fallback，降低后续字段演进导致缓存不可用的概率。
- 前端类型、Rust 后端检查和 diff 空白检查均已通过。
