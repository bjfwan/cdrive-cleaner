## CSD v0.1.2

新功能 + 工具链对齐版本。

### 新增功能

- **游戏库迁移**：独立 Tab，支持 Steam / Epic / Game Pass 三家平台
  - 自动检测注册表里的 Steam 路径，解析 `libraryfolders.vdf` 拿所有库，扫每个库下的 `appmanifest_*.acf` 列出已安装游戏
  - 解析 `C:\ProgramData\Epic\EpicGamesLauncher\Data\Manifests\*.item` 列出 Epic 游戏
  - 扫描 `C:\XboxGames\` 列出可迁移的 Game Pass 游戏，识别 `WindowsApps` 下受 TrustedInstaller 保护的游戏并标记为不可迁移
  - WindowsApps 类游戏单独分组，按钮直接跳转 `ms-settings:appsfeatures` 走系统原生迁移
- 游戏迁移直接复用现有 5 步迁移流程（copy → backup → junction → cleanup），用 `LinkType::Junction` 透明搬走，启动器可直接启动
- 搬运车支持游戏类型项目，与普通迁移共用批量执行流程，迁移历史里可区分（`link_type` 标记为 `game:Steam:<appid>`）
- 自带 VDF parser，解析 Steam 的 KeyValues 格式，4 个测试覆盖嵌套对象、字符串转义、行注释、错误终止

### 工程化

- TS / Vite 编译目标对齐到 ES2022，Tauri 2 的 WebView2（Chromium）原生支持，可放心用 `Array.prototype.at` 等现代语法
- `@tauri-apps/api` / `@tauri-apps/cli` 升到 2.11，与 Rust 端 `tauri 2.11.2` 对齐
- 新增 13 个游戏检测相关单元测试
