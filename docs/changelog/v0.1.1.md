## CSD v0.1.1

修复 + 工程化版本，无新功能。

### 性能修复

- **扫描进度线程 500ms 硬延迟**：每次扫描被强制等满 500ms 才能完成，已改成可中断 sleep。
  - 30 文件扫描：501 ms → 21 ms（**24× 加速**）
  - 1k 文件扫描：503 ms → 43 ms（12× 加速）
  - 真实 15k 文件目录：510 ms → 164 ms（3× 加速）
- **安全检测延迟**：
  - `C:\Program Files` 等"集合根"短路立即拒绝（2.8 s → 0.1 ms）
  - `C:\Users\<user>` 这种含大量 reparse points 的路径加深度上限（6.7 s → 0.6 s）
  - 加 30 秒结果缓存，重复点开秒响应（任意路径第二次起 0 ms）

### 工程化

- 加 MIT LICENSE
- 加 GitHub Actions CI（push/PR 自动 build + test）
- 加 GitHub Actions Release（打 tag 自动出 MSI/NSIS 包）
- 后端用 `tracing` 替换 `println!`，可通过 `RUST_LOG` 调级别
- 仓库结构扁平化，删除冗余双层嵌套和过期开发文档
- 加 21 个集成测试 + 多场景基准测试框架

### 新增功能

- 安全检测识别"集合根"（Program Files、Program Files (x86)、ProgramData、Users）并立即拒绝整迁
