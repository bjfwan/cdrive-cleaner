## CSD v0.1.8

本次版本聚焦性能优化与大规模数据场景下的稳定性：重复文件检测全面任务化、支持流式结果推送和取消；大文件视图和目录文件列表接入后端分页+前端虚拟滚动加载；全项目 Clippy 零警告。

### 新增功能

- **重复文件检测流式推送**：后端检测到确认的重复组后即时通过 `duplicate-group-found` 事件推送至前端，扫描过程中用户即可看到已发现的重复组，无需等待全部完成。
- **重复文件检测取消**：新增 `cancel_duplicate_scan` 命令，支持用户随时取消正在进行的重复检测。切换磁盘/组件卸载也会自动取消。
- **大文件分页加载**：新增 `get_large_files_page` 后端命令，支持按路径前缀、最小大小过滤和多种排序；前端 LargeFilesView 使用虚拟列表滚动到底部自动加载下一页（PAGE_SIZE=200）。
- **目录文件分页加载**：新增 `get_directory_files_page` / `scan_directory_files_page` 后端命令，带 5 秒 TTL 缓存；前端 ListView 直接文件列表使用分页+缓存，滚动到底部自动加载更多。
- **VirtualList 滚动触底事件**：VirtualList 组件新增 `scroll-near-end` 事件（endThreshold 可配置），为分页加载提供统一入口。
- **ExplanationTooltip LRU 缓存**：路径解释缓存增加 256 容量上限，避免长时间浏览后内存无限增长。
- **路径归一化工具模块**：新增 `scanner::path_utils` 公共模块，提供 `normalized_path_key`、`normalized_path_starts_with` 等路径归一化与前缀边界安全比较函数，统一消除各模块中的重复实现。
- **应用内自动更新**：启动时自动检查 GitHub Releases 最新版本（4 小时冷却），检测到新版本后可直接在应用内下载安装包（实时进度条），下载完成一键启动安装器并自动退出旧版本。支持设置中关闭自动检测或手动点击「检查更新」；下载失败时兜底跳转浏览器。

### 优化

- **重复检测分阶段哈希**：采用 quick hash (前 4KB) → partial hash (前+中+尾各 4KB) → full hash 三级策略，对大文件跳过不必要的全量读取，显著减少 IO。
- **重复检测 IO 节流**：使用 Semaphore 限制并发 IO 数量，避免在大量重复候选时打满磁盘。
- **前端并发控制**：LargeFilesView、ListView、DuplicatesView 均使用 `requestId` 单调递增机制过滤过期响应，防止快速切换目录时的竞态数据。
- **DuplicatesView pathSizeMap 增量更新**：流式接收重复组时增量更新路径-大小映射，避免每次全量重建。
- **全项目 Clippy 零警告**：修复 60+ 条 clippy lint（sort_by_key、map_or 简化、De Morgan 布尔化简、useless_conversion、strip_prefix、abs_diff、is_multiple_of、iterator flatten、collapsible_match 等），提升代码质量。

### 修复

- 修复 DuplicatesView 旧请求 `finally` 无条件关闭 listener 的竞态：旧扫描返回时不再误关新扫描的事件监听。
- 修复 `duplicate-group-found` 事件 payload 前后端不一致的问题：统一为 `{ root_path, request_id, group }` 结构。
- 修复 `find_duplicates_blocking_with_min_size` 仅测试使用但未标注 `#[cfg(test)]` 导致的 dead_code 警告。

### 工程化

- 新增 `path_utils` 模块被 `incremental`、`mft_usn`、`scan_index`、`disk_scanner` 统一引用，消除路径比较的分散实现。
- 新增 `DuplicateGroupEmitter` 类型别名和 `DuplicateScanRegistry` 注册表，管理活跃扫描的取消令牌。
- 后端分页命令统一参数风格：`offset` / `limit` / `sort`，limit 上限 500、默认 100。
- 新增 8 个重复检测单元测试（含 group emitter、cancellation、staged hash、partial collision）。
- 新增 scan_index 大文件分页集成测试。
- Cargo.lock 版本同步。
- 项目协议由 MIT 变更为 GPL-3.0-only，README、Cargo.toml、package.json 和关于页面统一更新。
