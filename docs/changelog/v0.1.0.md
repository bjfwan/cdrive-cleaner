## CSD - 磁盘空间管理 v0.1.0

首个公开发布版本，Windows 桌面应用，基于 Tauri 2 + Vue 3。

### 主要功能

- **磁盘扫描**：NTFS 卷支持 MFT + USN 深度扫描（管理员模式），普通模式自动回退到原生目录枚举
- **空间分析**：树状图、列表视图、大文件视图，支持下钻浏览目录
- **目录迁移**：把目录从一个磁盘迁到另一个，原位置创建 Junction/Symlink/Hardlink 占位
- **安全检测**：迁移前自动分析风险等级，阻止误迁系统关键目录
- **历史回滚**：完整迁移历史记录，可一键回滚

### 安装包

| 文件 | 类型 | 说明 |
|------|------|------|
| `CSD_0.1.0_x64-setup.exe` | NSIS | 推荐，体积更小 |
| `CSD_0.1.0_x64_zh-CN.msi`  | MSI  | 适合企业部署 |

### 系统要求

- Windows 10 / 11 (x64)
- WebView2 Runtime（安装时若缺失会自动下载）
- 推荐管理员模式运行以启用 MFT + USN 深度扫描
