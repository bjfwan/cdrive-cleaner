## CSD v0.1.3

新增垃圾清理 + 全套图标圆角刷新。

### 新增功能

- **垃圾清理**：独立 Tab，规则驱动地扫描 / 清理常见冗余文件
  - **80+ 条内置规则**，分 8 类：系统临时文件、浏览器缓存、Windows 更新残留、缩略图缓存、回收站、崩溃转储、应用日志、字体缓存
  - 规则三层定义：OS 层（`%TEMP%` / `%LOCALAPPDATA%\Temp` / `Prefetch` / `SoftwareDistribution\Download` / `WER` / `LiveKernelReports` / `FontCache` …）+ 浏览器层（Chrome / Edge / Firefox / Brave 各自的 `Cache` / `Code Cache` / `GPUCache` 等）+ 应用层（IDE、办公软件、聊天工具的可清理目录）
  - **三档风险标签**：`safe` / `caution` / `risky`，UI 显式渲染；Risky 规则默认不勾选
  - 自动识别 `requires_admin` 规则，标准权限下静默跳过并在结果里报告 `skipped_rules`
  - 路径解析支持 `*` 通配，例如 `%LOCALAPPDATA%\Google\Chrome\User Data\*\Cache`，自动展开各 profile
- **扫描进度事件**：`junk-scan-progress` 节流 80ms 增量发，前端实时刷新已完成规则数 / 找到条目数 / 累计可释放空间
- **清理走 `delete_path` 共用栈**：与迁移共用一条删除路径，支持「扔回收站」（推荐）和「永久删除」二选一，回收站模式可作为软兜底

### 视觉刷新

- **圆角 22% 重做整套图标**（与 Win11 / Edge / Office 的视觉对齐）
  - Windows: `icon.ico` / `Square*.png` / `StoreLogo.png`
  - macOS / Linux: `128x128.png` / `128x128@2x.png` / `256x256.png` / `32x32.png` / `64x64.png` / `icon.png`
  - Android: 各 dpi `mipmap-*` 下 `ic_launcher.png` / `ic_launcher_foreground.png` / `ic_launcher_round.png`
  - iOS: `AppIcon-*` 全套含 `AppIcon-512@2x.png`
- 配套脚本 `scripts/round-icons.ps1`：一键给 `src-tauri/icons/` 下 PNG 加圆角并重打 `icon.ico`，支持自定义 `-RadiusPercent`

### 工程化

- **`junk` 模块**：`rules.rs` + `rules_browsers.rs` + `rules_apps.rs` + `scanner.rs` + `cleaner.rs`，规则纯数据 / 扫描 rayon 并行 / 清理复用现有删除路径
- **8 个新增单元测试**：规则 ID 唯一 + snake_case ASCII / 每条规则非空路径 + 文案 / 回收站规则存在 / `env_path` 解析 / 规则数量地板（≥80）/ glob 模式（exact / prefix-suffix / star-only / middle）
- 文档同步：`docs/api.md`、`docs/development.md`、`README.md` 同步覆盖垃圾清理契约和命令注册
- `docs/junk-cleanup-contract.md` 新增，定义规则结构、风险等级语义、`scan_junk_files` / `clean_junk_files` 命令契约
