## CSD v0.1.4

前端性能全面重构 + 后端增量扫描一致性修复 + 扫描会话管理。

### 性能优化（前端）

- **长列表虚拟化**：ListView / LargeFilesView / JunkCleanView / DuplicatesView / History / Cart drawer 6 处全量 `v-for` 替换为自研 `VirtualList.vue`，千项列表滚动稳定 60fps
- **useCart 增量累加器**：7 个连锁 computed 替换为 `versionRef` + `Accumulator` 增量维护 + 版本缓存的懒 filter。新增 `addBatch` / `removeBatch` 批量 API，N 项写入只触发一次响应式 fan-out
- **useSelectionSet**：原地 Set + `triggerRef`，消除 `new Set(prev)` 的 O(n) 拷贝
- **进度事件节流**：`useThrottledShallowRef` 用 RAF + 时钟阈值将 `deep-scan-progress` / `incremental-scan-progress` / `junk-scan-progress` 统一限频到 ~12Hz
- **DeepScanProgress 按需挂载**：`v-show` → `v-if` + `defineAsyncComponent`，不扫描时完全不存在 event listener
- **SpaceTrend 单 computed**：4 次 O(n) 遍历（sparklinePath / sparklineFill / detailPath / detailFill + Math.min/max spread）合并为 1 次 for 循环
- **SmartGroupCard checkedSet**：模板里 N 次 `cart.has(path)` 替换为单个 Set computed；删除 `<TransitionGroup>` 动画开销
- **useCountUp 增强**：`minDelta` 跳过微量变化、`isVisible` 选项让不可见时跳过 RAF、`onScopeDispose` 防止 effectScope 销毁后泄露

### 性能优化（CSS / 渲染层）

- **移除所有 backdrop-filter**：8 处弹层的 `blur(18~24px) saturate(120%)` 统一为 `--modal-backdrop` 变量 + `.modal-overlay-base` 单一 `blur(10px)` 层（`@supports` 渐进增强）
- **移除 box-shadow 过渡**：所有 `transition` 中去掉 `box-shadow`（非合成层属性），只保留 `transform / opacity / background-color / border-color`
- **filter: blur(8px) 替换**：`.brand-mark::after` 改为静态径向渐变
- **`::-webkit-scrollbar` 去重**：`polish.css` 的 `* { scrollbar-width }` 改为仅对具体滚动容器设置
- **`contain: content`**：`.junk-row` / `.game-item` / `.table-row` / `.drawer-item` / `.preview-item` 等重复行加布局/绘制隔离
- **`content-visibility: auto`**：`.junk-collapse` / `.table-body` / `.drawer-list` / `.browse-body` 加延迟渲染
- **Welcome 动画压缩**：duration 砍半、链式延迟从 6 个错峰收为 2 个

### 后端：增量扫描一致性修复

- **`merge_scan_results_with_own` 权威回填**：合并完成后自底向上递归，用每个节点的 `own_size` / `own_file_count`（来自 DirectFilesOnly 重扫或缓存推算）+ Σ子节点重算 `size` / `file_count` / `dir_count`，消除"父被 Recursive 替换、子又走 DirectFilesOnly 把旧 children 覆盖回去"造成的统计漂移
- **`sanitize_tree_subtotals`**：在合并前对旧树做一次清洗，冻结已有偏差不再传递到下一轮
- **`ingest_changed_own` 递归**：changed_dirs 子树里每个节点的 own 值都覆盖到 `cached_own`，避免只浅扫一层导致沿用陈旧数据
- **时钟回拨保护**：`CLOCK_SKEW_TOLERANCE_SECS = 60`，mtime > now+60s 视为异常强制纳入重扫
- **合并后一致性校验**：`inconsistent_nodes` 计数 + 样本日志，便于追踪漂移

### 后端：扫描会话管理

- **CancellationToken + SessionRegistry**（`session.rs`）：每个磁盘同时只允许一次扫描会话；新会话自动取消旧会话；支持 `mark_completed` / `drop` 自动取消
- **`merge_scan_results_with_own_cancellable`**：权威回填阶段每 1024 节点检查一次取消信号，最坏 200ms 内响应
- **管理员重启 intent**（`pending_intent.rs`）：标准权限下点「开启管理员模式」时持久化 disk + timestamp → UAC 提权重启后自动恢复扫描
- **环境指纹缓存失效**（`env_fingerprint.rs`）：elevated / fs / volume_serial / app_version / rule_version / SID 任一变化时缓存自动作废，避免权限/环境变更后用错旧快照
