## CSD v0.1.5

JSON 化清理规则、深色主题、空间分解 + 系统回收，一次性把垃圾扫描从 6 秒砍到亚秒级。

### 性能：垃圾扫描架构重做

实测一次完整扫描耗时从 ~6.2 秒降到亚秒级，关键修复在三层：

- **`Box::leak` 不再每次扫描都泄漏**：新增 `OnceLock<Vec<PreparedRule>>` 缓存所有解析+展开+泄漏后的不可变规则数据，进程内只跑一次。重复扫描时只做文件系统 detect 探测和元数据克隆，每次零分配新增内存。新增单测 `load_json_rules_uses_static_cache_on_repeated_calls` 通过指针等价性验证缓存生效
- **`max_depth` 字段进入规则模型**：`JunkRule` 新增 `max_depth: Option<u32>`，scanner 在 pattern 递归分支按深度截断，`Some(0)` 表示只看 base 目录不递归。`TargetConfig` 同步加 `max_depth` JSON 字段（`#[serde(default)]`）
- **驱动器根安全网**：`rule_loader::effective_max_depth` 在加载阶段检测 "base 解析为驱动器根 + patterns 非空" 这一危险组合，自动注入 `max_depth=2` 并打 `[junk_perf] safety-net` warn 日志。配套单测 `json_rules_avoid_implicit_full_drive_scans` 在 CI 阶段拦截任何未来再写出全盘扫描组合的规则
- **修复语义错误**：`sys_chkdsk_fragments` 原本以 `%SYSTEMDRIVE%` 为 base + patterns `File*.chk`，每次扫描 DFS 整盘 ~6 秒只为找零个文件。改为两个 target（`%SYSTEMDRIVE%\\` 与 `%SYSTEMDRIVE%\\Found.*`）+ 显式 `max_depth=0`，符合 Windows chkdsk 实际碎片落地位置语义
- **同类隐患修正**：`sys_dumpstack_log` 显式 `max_depth=0`、`sys_uwp_general_temp` 显式 `max_depth=1`
- **性能埋点保留**：`tracing::info!(target: "junk_perf", ...)` 全链路覆盖 `[scan_junk_files] T0..T5`、`[rule_loader]`、`[scan_blocking]`（含 Top-15 慢规则、并行系数、p50/p95），生产开 `RUST_LOG=junk_perf=info` 即可现场抓数据

### 新增：清理规则 JSON 化

- 内嵌 10 个 JSON 规则文件（`clean_rules.json` + `clean/system|browsers|communication|dev_tools|games|multimedia|office|security|drivers_oem.json`），合计 660+ 条规则跨 9 个分类
- `rule_loader.rs` 负责解析 + 环境变量展开 + detect 探测 + glob 模式展开 + `max_depth` 安全网 + 转换为 `JunkRule`
- 兼容遗留硬编码规则源（`os_layer_rules` / `rules_browsers::extra_rules` / `rules_apps::extra_rules`），按 ID 去重合并

### 新增：空间分解 + 系统回收

- **SpaceBreakdown 视图**：按"系统/用户/可清理/未分类"四类拆解磁盘占用，支持下钻到具体路径，AC 引擎做规则匹配
- **SystemReclaim 面板**：Windows.old / WinSxS / Hibernate / Pagefile 等系统级占用一键释放
- **FolderRedirect**：Documents / Pictures / Downloads 等用户目录重定向到其他磁盘

### 新增：深色主题 + UI

- **三态主题**：light / dark / auto（跟系统）。`auto` 监听 `prefers-color-scheme` 实时切换。从老 `system` 字段平滑迁移，已设置的用户不丢偏好
- **Onboarding coachmark**：首次启动引导，覆盖核心交互
- **CommandPalette**：`Ctrl+K` 唤起的命令面板
- **BalanceSuggestion**：磁盘空间不均衡时给出迁移建议
- **CleanupResult feedback**：清理完成后的结果摘要弹层
- **图标重设计**：风险等级 / 文件类型 / 操作动作 三套图标统一风格

### 修复

- **`migrate_file` 目录统计可信化**：调用方传入的 `known_stats` 在目录场景下不再被信任（UI 层有时会传 `file_count=1` 占位），改为 `build_directory_copy_plan` 真实统计后比对，差异降级为 `tracing::debug` 而非中断复制。修复 SpaceBreakdown 入口迁移目录时被误判为"复制完整性失败"的回退
- **空间分解去重**：同一节点不会被多次纳入"可清理"分组
- **z-index / 深色主题 / SystemReclaim 显示问题**

### 工程化

- 新增 `useGameDetection.ts` composable：模块级缓存 + in-flight 共享，避免 GamesView 标签页切换重复触发 1-2 秒的 Steam/Epic/Game Pass 扫描
- 单测：57 项全过（rule_loader 12 + 其他 45），含 `is_drive_root` / `effective_max_depth` 4 例 / 缓存稳定性 / 全盘扫描审计
