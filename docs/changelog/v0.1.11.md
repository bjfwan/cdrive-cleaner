## CSD v0.1.11

v0.1.9 在更新机制和 AI 建议模块存在多处严重缺陷，国内用户基本无法正常使用这两项功能。v0.1.10 和 v0.1.11 均为修复 0.1.9 的问题，建议所有 0.1.9 用户立即升级。

### 更新机制修复

- **国内下载镜像加速**：设置 → 更新中可选 ghproxy 镜像或自定义镜像地址，安装包下载不再直连 GitHub
- **更新检查超时**：GitHub API 请求增加 15 秒超时，网络不通不再长时间挂死
- **检查失败弹窗保留**：网络不通时错误信息保持显示，支持一键重试
- **MSI 回退匹配**：查找安装包时自动回退到 MSI 文件

### AI 建议修复

- **事件负载匹配修复**：修复后端发送和前端接收的数据格式不一致导致建议从不显示的严重 bug
- **分析进度可视化**：点击 AI 分析后显示持续动画和耗时提示，不再闪现一下消失
- **scan_id 自动传递**：前端自动填入当前磁盘路径，解决命令缺少参数的问题
- **API 超时延长**：DeepSeek API 超时从 60s 延长到 120s，兼容较大磁盘快照的处理时间
- **Worker 响应流修复**：Cloudflare Worker 改用完整缓冲返回，修复 HTTP/1.1 客户端无法读取响应的问题
- **提示词中文化**：系统与用户提示词全面中文化，AI 返回中文建议
- **文件分类细化**：新增 system_files、model_files、game_files、media_files 等 10 个分类，AI 根据真实类型判断安全性，不再把系统文件当成可删除项
- **TLS 兼容性**：ureq 切换到 Windows 原生 TLS（schannel），修复管理员权限下 HTTPS 连接问题
