3. 美化滚动条样式
4. 最终决定：小窗口（<900px）时隐藏"最大的目录"列表，只显示树状图保持简洁

- 但单文件迁移时后端没有实时进度，无法显示速度和剩余时间

**计算逻辑：**
```javascript
// 速度 = 已传输大小 / 已用时间
speed = transferredSize / elapsedTime

// 剩余时间 = 剩余大小 / 当前速度
remainingTime = remainingSize / speed
```

## 🎯 待完成功能（Phase 3-6）

### Phase 3: 智能迁移安全检测（优先级：最高）⚠️

#### 1. 迁移安全检测引擎 �️
**优先级：** ⭐⭐⭐⭐⭐  
**预计时间：** 8-12 小时  
**状态：** 核心功能，必须优先实现

**功能描述：**
智能分析文件/目录是否可以安全迁移，防止系统崩溃和软件损坏。

**核心需求：**
- 在绝对确保安全的前提下，尽可能允许迁移
- 多层检测机制，提供准确的风险评估
- 明确的风险分级和用户提示
- 可扩展的规则引擎

**技术方案：**

**A. 多层检测系统**
```rust
// 1. 路径模式检测（黑/白名单）
// 2. 注册表依赖检测
// 3. 文件占用检测
// 4. DLL 依赖分析
// 5. 便携式应用特征识别
// 6. 综合评分系统
```

**B. 风险分级**
- 🔴 **危险**（Dangerous）：系统关键目录，绝对禁止
  - `C:\Windows\`
  - `C:\Program Files\WindowsApps\`
  - `C:\ProgramData\Microsoft\Windows\`
  - 正在运行的系统进程
  
- 🟠 **高风险**（Risky）：已安装程序，强烈不建议
  - `C:\Program Files\` 下有注册表依赖的应用
  - 文件被占用
  - 有 DLL 依赖的可执行文件
  
- 🟡 **中风险**（Moderate）：可能影响软件运行
  - `C:\Program Files\` 下的便携式应用
  - 游戏目录（Steam、Epic）
  - 部分 AppData 目录
  
- 🟢 **安全**（Safe）：推荐迁移
  - `C:\Users\[用户]\Downloads\`
  - `C:\Users\[用户]\Documents\`
  - `C:\Users\[用户]\Videos\`
  - `C:\Users\[用户]\Pictures\`
  - `C:\Users\[用户]\Music\`

**C. 依赖库选择**

**规则引擎：**
- `rusty-rules` - JSON 配置的规则引擎
- 支持复杂逻辑组合（all, any, not）
- 可外部配置，易于更新规则

**Windows API：**
- `winreg` - 注册表访问
- `pelite` - PE 文件解析（DLL 依赖）
- `windows` - Windows API 绑定

**实现步骤：**

**Step 1: 基础检测（4 小时）**
- [ ] 添加依赖库（rusty-rules, winreg）
- [ ] 实现路径黑/白名单检测
- [ ] 实现文件占用检测
- [ ] 创建风险评分系统

**Step 2: 高级检测（3 小时）**
- [ ] 实现注册表依赖检测
- [ ] 实现便携式应用特征识别
- [ ] 添加 DLL 依赖分析（可选）

**Step 3: 规则引擎集成（2 小时）**
- [ ] 配置 rusty-rules 引擎
- [ ] 创建 JSON 规则配置文件
- [ ] 实现规则评估逻辑

**Step 4: 前端集成（3 小时）**
- [ ] 添加风险等级显示（颜色标记 + 图标）
- [ ] 实现风险详情弹窗
- [ ] 添加"我了解风险"确认机制
- [ ] 禁用危险项目的迁移按钮

**数据结构：**
```rust
#[derive(Debug, Serialize)]
pub struct MigrationSafety {
    pub risk_level: RiskLevel,

}
```

## 💡 开发经验总结

### Vue 响应式陷阱
1. **Set/Map 响应式问题：** 直接修改 Set/Map 不会触发更新，需要创建新对象
   ```javascript
   // ❌ 错误
   selectedItems.add(item)
   
   // ✅ 正确
   selectedItems = new Set([...selectedItems, item])
   ```

2. **事件重复触发：** 避免在父子元素上绑定相同事件
   ```vue
   <!-- ❌ 错误：点击触发两次 -->
   <td @click="toggle">
     <input @change="toggle" />
   </td>
   
   <!-- ✅ 正确：只在 input 上绑定 -->
   <td @click.stop>
     <input @change="toggle" />
   </td>
   ```

### Flexbox 布局技巧
1. **子元素收缩问题：** 添加 `min-height: 0` 让 flex 子元素正确收缩
2. **响应式网格：** 使用 `minmax()` 实现灵活的列宽
3. **小窗口优化：** 使用 `@media` 隐藏次要内容，保持核心功能

### 性能优化经验
1. **动画性能：** 使用 `will-change` 提示浏览器优化
2. **缓动函数：** `cubic-bezier(0.4, 0, 0.2, 1)` 提供自然的动画效果
3. **批量操作：** 使用 Set 数据结构提升查找性能

### UI/UX 设计原则
1. **渐进增强：** 小窗口时隐藏次要功能，保持核心体验
2. **视觉反馈：** 所有交互都应有明确的视觉反馈
3. **一致性：** 统一的圆角、间距、阴影风格
4. **性能优先：** 动画流畅度优先于复杂效果
