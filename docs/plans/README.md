## 📖 项目概述

### 项目背景

C 盘空间不足是 Windows 用户的常见问题。传统的清理工具要么只能删除文件（可能导致程序无法运行），要么需要手动移动文件并修改配置（操作复杂且容易出错）。

本项目通过**智能迁移 + 符号链接**技术，在不影响程序正常运行的前提下释放 C 盘空间。

### 核心特性

#### 1. 智能迁移
- **不是简单删除**：将文件迁移到其他盘，保留原有功能
- **自动创建符号链接**：程序访问原路径时自动重定向到新位置
- **透明操作**：对应用程序完全透明，无需修改配置

#### 2. 安全保障
- **多层安全检测**：系统关键路径、进程运行、文件占用、注册表依赖
- **风险评估**：0-100 分综合评分，四级风险分级
- **智能识别**：自动识别 Steam/Epic 游戏、便携式应用等
- **失败回滚**：任何步骤失败自动恢复原状

#### 3. 高性能
- **快速扫描**：30-60 秒扫描 C 盘（500GB，50万文件）
- **并发处理**：使用 tokio 异步运行时，充分利用多核 CPU
- **内存优化**：流式处理，内存占用 < 200MB
- **缓存系统**：重复扫描速度提升 90%+

#### 4. 用户友好
- **现代化 UI**：Vue 3 + ECharts，响应式设计
- **实时反馈**：扫描/迁移进度实时显示
- **批量操作**：支持批量选择和迁移
- **可视化**：树状图直观展示空间占用

### 目标用户

- **主要用户**：开发者、技术人员
- **次要用户**：普通用户（通过 GUI）
- **未来计划**：开源到 GitHub，服务更广泛的用户群体

## 🛠 技术栈

### 前端技术

**Vue 3 + TypeScript**
- **选择理由**：
  - 响应式系统适合实时更新进度
  - TypeScript 提供类型安全
  - 组合式 API 便于逻辑复用
  - 生态成熟，组件丰富

**ECharts**
- **选择理由**：
  - 强大的数据可视化能力
  - 支持树状图（Treemap）
  - 交互性好，支持钻取
  - 性能优秀，可处理大量数据

### 后端技术

**Rust + Tauri 2.0**
- **选择理由**：
  - Rust 性能接近 C/C++，内存安全
  - Tauri 打包体积小（3-5MB vs Electron 50-100MB）
  - 跨平台支持
  - 原生性能，低内存占用

**关键依赖：**
- `tokio` - 异步运行时，支持并发扫描
- `windows-rs` - Windows API 绑定
- `winreg` - 注册表访问
- `rusqlite` - SQLite 数据库
- `sysinfo` - 系统信息获取
- `walkdir` - 文件遍历
