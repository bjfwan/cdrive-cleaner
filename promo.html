Core Features

从扫描到迁移，一站式解决

不只是告诉你空间去哪了，还帮你安全地搬走它

🔍

极速磁盘扫描

管理员模式走 NTFS MFT + USN Journal，几十万文件秒级完成。普通权限自动回退原生枚举，功能不打折。第二次扫描走增量，只重扫变更子树。

📊

多维空间分析

Treemap 面积图一眼看胖子，List 列表按大小/名称/时间排序，Large Files 跨目录挑大文件，Smart Groups 自动分组标记可清理/可迁移/系统关键。

🚚

目录安全迁移

copy → verify → backup → create-link → cleanup 五步事务。原位置留 Junction/Symlink，应用零感知继续运行。CopyFile2 大文件 unbuffered IO + Rayon 并行复制。

🛡

四级安全检测

迁移前自动跑安全分析：路径白名单 → 应用类型识别 → reparse 深度 → 进程占用 → 注册表关键键。系统关键目录硬拒绝，绝不踩坑。

🎮

游戏库一键迁移

自动识别 Steam / Epic / Game Pass 已安装游戏，免去手工找路径。Junction 链接让启动器无缝运行，专属迁移记录追踪每一款游戏。

⏰

历史回滚 & 趋势

每次迁移完整记录到 SQLite (WAL)，一键回滚到原状。Space Trend 90 天空间走势图，持续监控磁盘健康。重复文件检测 (xxhash) 批量清理。
